Privacy Policy

AquaFlow Manager · DevAxis (Pvt.) Ltd. · Effective 6 October 2026

1. Who this policy covers

This policy describes information handling by the AquaFlow Manager Windows desktop application developed by DevAxis (Pvt.) Ltd., and this public product-information website.

2. Business records stored locally

The application stores the information you enter or generate, such as product names and pictures, categories, prices, branch details, stock movements, sales, customer details, invoices, estimates and application settings. These records are used to provide the inventory, sales, document and reporting features.

Records and local backups are saved on your Windows computer. A full database backup can include customer contact information and all other saved business records. You control where copies of these files are kept and with whom they are shared.

3. Information accessed through Google

If you choose Connect Google Drive, Google's authorization page asks you to permit the application to use the https://www.googleapis.com/auth/drive.file scope. This limited permission covers files created by the app or made available to it through your authorization.

The integration uses:

  • Your connected Google account email address, so the application can display which account is connected.
  • Storage-quota information, so the application can display account storage usage and determine whether space is available for an upload.
  • Backup file contents when uploading or downloading a database snapshot, and file metadata such as names, IDs, sizes, checksums, timestamps and application markers to identify and verify backups.
  • Google access and refresh tokens to perform the backup operations you authorize and renew the connection when permitted by Google.

Uploads are placed in the connected account's Pak Water Filters Backups folder. File checksums and sizes are used to confirm completed transfers. The application can reuse an identical backup instead of uploading another copy.

The integration does not request access to Gmail messages or Google Photos. A storage-usage display may include space shared with Gmail and Photos; this display uses account-quota information.

4. How Google information is used and shared

Google information is used to connect the selected account, upload and verify backups, find and download compatible backups, display storage usage and manage older app backups when you enable cleanup.

Backup transfers are made between your computer and Google Drive. This integration does not send business backups or Google login tokens to a DevAxis backup server. Google processes the information transmitted to its services under its Privacy Policy.

DevAxis does not sell Google user data, use it for advertising, or use it to train AI models. The integration does not provide DevAxis with automatic access to the contents of your backups. If you choose to share a file or screenshot for support, share only what is necessary; it will be used to address your request.

AquaFlow Manager's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

5. Storage and security

The application does not collect or store your Google password. Login takes place through Google's browser-based authorization flow. Google tokens are stored locally using Windows Data Protection API protection associated with the signed-in Windows user.

Business databases and backup files are standard SQLite files. They are not automatically password-encrypted by AquaFlow. Keep your computer and backup locations secure and manage the sharing permissions of your Drive files.

Local connection state can include the connected email, folder and backup file IDs, storage usage, pending-upload details, timestamps, checksums and an installation identifier used to distinguish this installation's backups.

6. Backup retention and pending uploads

Local records and backup files remain until you remove them. Drive backups remain in your account until you remove them or enable the optional older-backup cleanup feature.

Cleanup is off by default. When enabled, it runs after a new upload has been verified. It preserves the latest two completed snapshots and selects up to seven daily and four weekly representative copies. Those groups may overlap. It targets about 1 GB for retained copies, while protecting the latest two; large protected files can exceed this target.

Cleanup permanently removes eligible older backups marked for the current installation. It preserves local backups, unrelated Drive files and backups belonging to other installations.

If an upload cannot finish, the local backup remains and the latest pending request is retained locally. While the application is open and connected, it can retry the request. When saved records have changed before a retry, the application can create a fresh snapshot containing the latest saved data.

7. Your choices and deletion

  • Use the application and local backup features without connecting Google Drive.
  • Use Disconnect in Settings to remove this installation's saved Google login and disable its cloud connection. Existing backup files remain in Drive.
  • Revoke AquaFlow access through your Google Account connections.
  • Delete cloud copies in Google Drive and manage local copies in AquaFlow's backup list or your local backup folder.
  • Enable or disable automatic older-cloud-backup cleanup in Settings.

Disconnecting or revoking permission does not by itself delete local business records or existing cloud backups. Reinstalling software also does not guarantee deletion of retained local data. Contact support if you need help locating files.

8. This website

This informational website has no account login, payment form, advertising scripts or developer-installed analytics. When hosted on GitHub Pages, GitHub processes connection information, including visitor IP addresses, for hosting and security as described in its Privacy Statement.
